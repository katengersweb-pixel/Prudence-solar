

# 1. Design vision

Create a clean, premium, trustworthy solar energy website that feels like an established scientific and renewable-energy company rather than a generic template.

The design should balance three qualities:

- Trust: clear company information, real project photographs, genuine reviews, and professional typography.
- Energy: bright solar imagery, sunlight-inspired accents, and confident calls to action.
- Scientific credibility: structured layouts, precise information, restrained visual effects, and transparent calculator estimates.

The experience should feel welcoming to homeowners while remaining professional enough for commercial and industrial customers.

# 3. Typography

Use a modern, readable sans-serif family such as Inter or Manrope.

| Element         | Desktop guideline | Weight   |
| --------------- | ----------------- | -------- |
| Hero headline   | 48–60 px          | Bold     |
| Section heading | 32–40 px          | Semibold |
| Card heading    | 20–24 px          | Semibold |
| Body text       | 16–18 px          | Regular  |
| Supporting text | 14–15 px          | Regular  |
| Button text     | 15–16 px          | Semibold |

On mobile, reduce the hero headline to approximately 34–40 px and section headings to 26–30 px.

Keep line lengths comfortable, use consistent spacing, and avoid excessive uppercase text.

# 4. Page layout and composition

- Maximum main content width: approximately 1200–1280 px.
- Desktop side margins: fluid, with generous whitespace.
- Standard section padding: 72–96 px vertically on desktop and 44–64 px on mobile.
- Card corner radius: 12–18 px.
- Use a consistent spacing scale based on multiples of 8 px.
- Use subtle shadows only when they help establish depth.

The page should alternate between white and soft-neutral sections. Avoid making every section a separate boxed card.

# 6. Component and interaction design

Use reusable components instead of designing every section independently.

| Component     | Behavior                                        |
| ------------- | ----------------------------------------------- |
| Header        | Sticky navigation; responsive mobile menu       |
| Hero carousel | Four slides; autoplay and manual controls       |
| CTA button    | Consistent hover, focus, and pressed states     |
| Product card  | Image, title, description, enquiry action       |
| Statistics    | Verified values; optional count-up animation    |
| Calculator    | Input validation, recalculation, result display |
| Gallery item  | Responsive image; optional lightbox             |
| Review card   | Consistent testimonial layout                   |
| Enquiry form  | Validation, loading, success and error states   |
| Footer        | Working navigation and contact links            |

### Interaction principles

- Hover effects should be subtle and quick.
- Buttons should have visible hover and keyboard focus states.
- Avoid parallax, constant floating effects, or excessive scroll animations.
- Respect reduced-motion settings.
- Never make a decorative element appear to be an interactive control.
- All actions must work with mouse, keyboard, and touch input.

# Prudence Solar & Scientific Solutions — Design Specification

Design a premium, professional, responsive corporate website for Prudence Solar & Scientific Solutions.

Brand tagline: “Inspired by Science. Powered by Sun.”

## Brand rules

- Use the original supplied Prudence logo without changing its shape, colors, proportions, or tagline.
- Primary navy: #102B50.
- Sustainability green: #4D922D.
- Solar gold: #F7A900.
- Main background: #FFFFFF.
- Alternate background: #F5F7FA.
- Use Inter or Manrope typography.
- The overall design must feel trustworthy, modern, scientific, clean, and professionally art-directed, not like a generic AI-generated template.

## Layout

Create a well-spaced, responsive single-page corporate website with these sections in this order:

1. Header and four-image solar hero carousel.
2. Trusted partner introduction.
3. Company statistics.
4. PM Surya Ghar scheme section.
5. Interactive solar calculator.
6. Customer installation gallery.
7. Customer reviews.
8. Enquiry form.
9. Contact information, location, and footer.

Include all six company product categories: Quality Solar Panels, Solar Street Lights, On-Grid Solar Systems, Solar Motors, Solar Water Heaters, and Solar Security Cameras.

## Visual direction

Use high-quality solar photography, generous whitespace, clear typography, subtle shadows, 12–18 px card radii, restrained gold accents, and occasional green highlights. Avoid excessive gradients, glowing borders, oversized decorative shapes, excessive animations, and cluttered layouts.

The hero must have four distinct images, readable text overlays, manual carousel controls, and prominent “Get a Free Quote” and “Explore Solutions” buttons.

Use a two-column introduction section, a three-item statistics section, a dedicated scheme feature panel, a well-organized product showcase, a responsive photo gallery, clean testimonial cards, a professional enquiry form, and a navy footer.

## Interaction and accessibility

- Make navigation, CTA buttons, carousel controls, form inputs, phone links, and map links functional.
- The solar calculator must use documented formulas and validated assumptions.
- The enquiry form must connect to a real configured submission destination before being considered complete.
- Use semantic HTML, accessible labels, visible keyboard focus, suitable contrast, and reduced-motion support.
- Optimize images and ensure there is no horizontal overflow on mobile.

## Content integrity

- Use real company information and the supplied logo.
- Do not invent statistics, certifications, prices, testimonials, or customer photographs.
- Use clearly marked development placeholders wherever company information is missing.
- Link PM Surya Ghar to the official government portal.
- Clearly label solar estimates as indicative and subject to site assessment.

## Implementation process

First inspect the existing project, identify its framework and structure, and preserve working code. Then implement the shared design system and page layout. Do not rewrite the entire project or install unnecessary dependencies without a clear reason.

Build in small stages and test each stage before proceeding. Finish with responsive checks, functional testing, accessibility review, and a production build.

This design document is the visual companion to the PRD: the PRD defines what Prudence needs; the design document defines how the website should look and how its interface should behave.
